Hons-Thesis-identifying-putatively-Human-specific-brain-expressed-lncRNAs

Developing a computational framework for identifying human-specific brain-expressed lncRNAs. This repository contains the code used to establish our developed computational framework in my Honours Project at the University of Cape Town. Some scripts may need to validated for full reproducibility. 

The repository is split into five main steps, each of which contain code and a README.md file detailing the contents of each step.
