Hons-Thesis-identifying-putatively-Human-specific-brain-expressed-lncRNAs

Developing a computational framework for identifying putatively human-specific lncRNAs that are expressed in the human brain. This repository contains the code used to establish our developed computational framework in my Honours Project at the University of Cape Town. 

The repository is split into five main steps, each of which contain code and a README.md file detailing the contents of each step. In addition, some scripts may need to validated for full reproducibility. 

Important to note: only the main processing scripts are included, some intermediate scripts are not.
